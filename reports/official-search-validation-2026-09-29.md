“候选行数”是各 query 返回条目数之和，含跨 query 重复；不是 21 个独立相关事件。另一次人民网 HTTP 地址诊断返回 403，不在上述 HTTPS 客户端的 12 次请求中。

首次四组 query 为“常德 养老金 拾荒”“张雪 机车 被盗”“王楚钦 阿拉米扬”“王曼昱 蒯曼 11比0”。中新网前三类中的养老金、被盗以及王曼昱具体赛果没有命中；“王楚钦 阿拉米扬”返回五条候选。追加查询“王曼昱 亚运会”“王楚钦 阿拉米扬 亚运会”“张雪”“养老金 拾荒”后又获得十六行候选。

这批结果说明仍需要二次判定：

- “王楚钦 阿拉米扬”可以命中同一篇综合报道里的不同比赛，也可以命中往年比赛，并不等同于目标半决赛。
- “张雪”可以命中记者张雪松、同名游客以及其他机车报道，不能证明目标车辆被盗。
- “养老金 拾荒”可命中过往其他老人和慈善故事，不能直接支持常德目标事件。
- 王曼昱采访的两条文字／视频标题与原始采访摘录关联较明确，作为待人工复核的自然正例；综合报道与单场赛果的关系有歧义，未强行纳入正例。

17 条候选摘录被纳入 v0.3 相关性／匹配用例，各生成一条事件匹配与一条官媒支持测试。公开文件只保留必要摘录，不含采样正文、凭据、Cookie 或 API key。

生产链路的 query 生成、限额、缓存、搜索失败状态、候选落库及引用关联另有自动化集成测试。这里的 12 次请求验证真实端点，不是 12 轮生产九步链路，也没有在本轮重新实测知乎或微博。
