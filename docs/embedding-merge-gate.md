# Embedding 与 reranker 联合判定

更新日期：2026-10-24。[返回项目首页](../README.md) · [事件匹配](event-matching.md) · [官媒补证](official-evidence.md)

## 规则

针对10月23日实测的无关高分，增加独立的 embedding 门槛，不把两个分数相加平均。覆盖知乎↔微博、微博↔官媒、官媒↔知乎的共享事件匹配器，以及官媒补证判断。共享匹配器中的同平台语义候选也使用同一门槛。

| 情况 | 处理 |
| --- | --- |
| 同一 ID／URL | 仍走身份匹配，明确事件冲突检查保留 |
| embedding < 0.60 | 不归并该候选，允许原话题独立创建，不因 reranker 虚高排入审核 |
| 0.60 ≤ embedding < 0.70 | 标题包含，或实体与动作都重合时，才允许继续自动归并判断；否则转审核 |
| embedding ≥ 0.70 | 继续原有判断，高分正文路径仍要求 reranker≥0.95、文本条件、无明确冲突或模型异常 |
| 启用了语义判断但 embedding 缺失 | 转审核，不允许高 reranker 单独放行 |

官媒补证不自动为待审核关系建立支持引用：低分、中间区间无锚点或缺失 embedding 时均不接纳为证据，保留比较记录。规则模式未启用模型时不强求模型分数。官媒文章自带链接不等于它与目标事件已有同一身份关系。

低 embedding 候选在排序前降分；中间区间缺锚点或缺失分数的候选最高到审核置信度，防止错误的高 reranker 抢占合理目标。来源范围使用统一规则，避免仅在 CLI 正文放行分支加条件，而旧实体匹配路径或官媒补证继续绕过门槛。

## 依据与限制

本次固定门槛基于本项目样本，不是通用概率标准。博览会／地震0.337、电影／城市大会0.397、电竞／网球0.454等负例会被阻止归并；同场男团比赛0.739、女团比赛0.773、CBA同场比赛0.795保留继续判断资格。

女团与男团不同比赛约0.693，缺少明确事件锚点时进入审核。不同长征纪念活动约0.679也需要额外依据。主题相近、分数高并不保证同一事件，未来仍需改善输入组织和比赛、地点、时间等具体事件身份检查。

门槛常量集中在 `app/services/semantic_agreement.py`；匹配器与补证路径共用该策略。没有更换模型或修改模型分数缓存格式，因为此次改变的是决策规则而非模型输出。旧的匹配决定和人工审核不会自动重写；如需修正历史归并应另行执行回放或人工调整。

## 验证

`test_embedding_agreement.py` 覆盖三类来源组合、阈值边界、已有身份、缺失模型分数、低分误候选排序、官媒补证及规则模式；复用已保存正负例指标做无网络回归。`test_cli_semantic_merge.py` 和多候选测试补齐 embedding 输入，继续验证正文、冲突和竞争候选保护。

不重新请求 CLI、不发送邮件。本次未改变官媒正文提取和热度公式。
