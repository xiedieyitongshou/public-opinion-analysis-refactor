# 简报历史版本的时间与来源

[返回 README](../README.md) · [按简报复核](review-report-binding.md)

## 界面说明（2026-11-03）

简报卡片和展开后的每个历史版本均显示以下信息，时间统一转换为北京时间：

- **简报范围**：本版简报保存的起止窗口，不等于这段时间内一直在抓取数据。
- **数据采集**：该期关联的原始采集记录中的最早与最晚观测时间，并列出采集轮数。单轮只显示一个观测时点；多来源完成时间不同时显示范围。
- **采集来源**：关联记录中实际有数据的来源；保存了 CLI 返回样本时，同时列出微博 CLI。
- **版本生成**：此版本的创建时间。历史数据回放、重建或审核更正会生成新版本，但不会把原采集时间改成处理时间。

汇总简报从 `report_window.run_ids` 关联的各轮采集读取记录，避免只展示汇总对象保留的最后一轮。历史更正版本沿用同一期的来源记录，各版本分别保留生成时间。简报窗口外的采集不混入当前卡片。

旧数据缺少完整采集记录时，优先参考本版保存的来源引用，并标注“按引文记录”；缺少部分轮次时标注“记录不完整”。没有时间证据的显示“未记录”，不会根据版本日期、报道发布时间或默认24小时窗口推算采集时间。

## 实现边界

`/api/reports`、详情和历史版本接口增加 `window_start` 与 `collection_provenance`，由已有记录只读计算，不新增数据表，不修改历史简报正文、归并、审核或采集调度。实际采集时间依据来源的 `observed_at`，缺失时使用该轮条目的 `fetched_at`；它不是新闻发生时间或报道发布时间。

回归覆盖旧材料新回放、汇总多轮、历史更正、缺失轮次、窗口隔离及旧引文回退，并验证前端北京时间和历史展开显示。
