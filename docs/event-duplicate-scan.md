# 社区事件周期查重

## 扫描范围与判断

调度器每八小时创建一次扫描，选取扫描时刻之前二十四小时内有有效热榜观测的社区事件。
有效观测需同时具有成功的采集状态、明确的在榜记录及窗口内的观测时间。
事件需处于 active 状态，官媒 F 类独立议程事件排除在扫描范围外。

事件按稳定 event_id 排序，枚举所有 i < j 的事件对。每个无序事件对只列入一次。
材料直接进入 DeepSeek 配对判定器，扫描流程没有检索预筛选。
材料复用已接纳的 CLI 正文与问题描述，保留既有单文档长度上限和截断标记。

复用 `LLMPairDecision`、`judge_pairs`、JSON Schema 校验及双方原文引用校验。
批次最多包含十个候选，输入超过既有字符预算时拆分批次，剩余事件对继续排队。
同一具体事件以及具备双方具体线索的 possible_same_event 进入人工审核。
一般信息不足、相关但不同及明确不同的判断保留在审计缓存中。

## 人工审核

审核类型为 `event_duplicate_candidate`，绑定双方观测对应的采集 run_id，出现在相应简报的审核队列中。
界面展示两个已有事件的来源、正文、判断理由及引文，提供逐条确认归并、保留两个事件和忽略操作。
提交归并时重新核对两边的 active 状态、社区身份和材料版本。

人工确认后移动来源记录到目标事件，将原事件标记为 merged 并保存目标引用。
原始历史快照和已保存简报保留，沿用审核后的观测重建与简报草稿更新流程。
人工归并使相邻查重任务的旧材料失效时取消旧审核项，后续扫描可基于更新材料重新提出候选。

## 缓存和恢复

新增轻量 `event_pair_judgments` 表保存通过校验的事件对结果。
主键包含双方稳定 ID、事件材料、配置的模型名、服务地址、完整 Prompt、Prompt 版本及输出 Schema。
正文、标题、来源或模型与 Prompt 变化会生成新的判断键。
热度、点赞数及重复观测的采集时钟不进入材料键。
完整材料哈希参与键计算，因此截断位置以后的正文变化也会触发重新判断。

持久事件对缓存可跨过普通 LLM 响应缓存的二十四小时有效期。
每批有效结果与扫描游标一起提交。批次失败时优先恢复既有配对缓存中的成功结果。
结构或引用校验失败的事件对在首遍结束后等待五分钟，再安排一次小批量恢复。
恢复继续使用原 run_id 和累计预算。持续的服务或网络错误中断当前分段并限制恢复次数。
达到请求或 token 预算时记录 `budget_exhausted`，保存游标和已完成结果。

## 调度与预算

复用 JobCoordinator、analysis 租约、AgentTask、RequestLog 与 RunTokenBudget。
查重由既有 worker 入口分段执行。普通采集队列优先，查重执行期间调度器仍检查采集预约。
每批前检查待执行采集，当前外部请求返回后让出 worker。
父进程监督每段墙钟超时，进程异常时保留原任务游标与预算，最多恢复一次。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `EVENT_DUPLICATE_SCAN_ENABLED` | `true` | 开启八小时扫描，需已配置 DeepSeek Key |
| `EVENT_DUPLICATE_MAX_CALLS_PER_SCAN` | `300` | 一次完整扫描含恢复的累计请求上限 |
| `EVENT_DUPLICATE_TOKEN_BUDGET_PER_SCAN` | `2000000` | 一次扫描累计 token 预算 |
| `EVENT_DUPLICATE_SLICE_SECONDS` | `45` | 每段执行时间，父进程另保留单次请求收尾时间 |

扫描直接使用 DeepSeek，开关独立于增量归并的 rules／llm 选择。
每段最多发起两个批次，扫描跨段共享配额。提供方未返回 usage 时沿用保守预留计费。
配额随新的八小时扫描重新建立，完成过的事件对优先读取持久缓存。
同一时刻只执行一个扫描，前次仍在排队或执行时继续其断点。

## 验证

使用 2026 年 11 月 5 日下午五轮采集数据库副本完成了 63 个社区事件、1,953 对的隔离检查。
首遍和恢复累计 245 次请求，所有事件对最终通过结构及引用校验。
同材料重复运行和实际 worker 入口各验证了 1,953 对持久缓存命中与零新增模型请求。
本次发现的疑似重复保存在隔离审核队列。语义复核仍发现范围过宽的建议，因此保留人工确认环节。

回归覆盖时间窗口、失败观测与 F 类排除、无序全量枚举、缓存失效、断点续跑、预算守恒、
采集优先级、网络异常停止、人工确认与材料变更后的归并拦截。
